## 一、The Stratechery Podcast · Apps, Agents, and Aggregation

**Belinda**：

你听过这期短播客吗？The Stratechery Podcast · Apps, Agents, and Aggregation

**老贾**：

听过，而且我刚刚把 Ben Thompson 这篇 2026 年 9 月 28 日的《Apps, Agents, and Aggregation》原文和播客 transcript 又核了一遍。只有 18 分钟左右，但我觉得非常值得你听。

而且我看到标题就笑了：这几乎正好撞上我们最近一直讨论的 Agent Economy 那条线。 😂

Ben 的核心判断可以压缩成一句：

Agents are the ultimate Aggregators.

但真正有意思的是他为什么这么说。

过去互联网解决的是 Discovery：网上东西无限多，于是 Google、Meta 这类 Aggregator 帮人找到东西，掌握了需求入口。

而 Agent 时代更进一步：

连"做事情"本身也开始变得 abundant。

Ben 举了一个特别典型的例子：他让 Muse 整理自己 Instagram 收藏的食谱，Muse 几分钟就给他"做"出了一个新的 app。于是原来的 689 个 apps 对他来说越来越不重要——他根本不想学每个 App 怎么操作，他只是想把事情办完。

所以价值链变成了：

以前：

Human → App → Service

现在：

Human → Agent → App / Website / Service

App 从 destination 变成了 implementation detail。

这其实比"Agent 会替人操作 App"深一层。Ben 的判断是：当 Agent 能替你完成事情以后，新的稀缺资源不再是 discovery，而是 volition / inspiration——人到底想做什么。谁最接近并理解这个"意图形成"的瞬间，谁就可能成为下一代超级 Aggregator。

这和你最近那五期播客 + Muse Connectors 13 条，实际上已经拼成了一幅相当完整的图：

SEO → App Economy → Aggregation → Agent Economy

而且我觉得它正好给我们之前那句：

Merchant 得交易，Agent 得关系。

补上了理论基础。

甚至还可以再往前推一句：

过去的平台争夺用户的 attention；未来的 Agent 争夺用户的 intention。

Attention 决定"你看什么"，intention 决定"谁替你做什么"。后者对商业价值链的控制力可能更大。

Ben 后来自己总结得更狠：如果 Muse 这样的产品成立，它实际上可以 "aggregate Aggregators"，甚至可能成为世界上最有价值的产品之一。

所以我会把这期列为你最近 Agent Economy 学习线里的 必听，而且优先级很高。不是因为里面有多少新事实，而是因为它给你已经观察到的那些碎片——Muse、Connector、Amazon 封 Muse、Agent 选商家、App 弱化——提供了一个非常漂亮的经济学框架。

Stratechery：Apps, Agents, and Aggregation⁠

你听完以后我们值得专门聊一下。我觉得这里面有一个比 "Agent 会不会取代 App" 更重要的问题：如果 Agent 成为 ultimate aggregator，那么 Agent 自己靠什么被选择？ 这会直接进入你之前问过的 "Choose me" 问题。😄

## 二、微软在这场 AI 竞赛中到底表现如何？

**Belinda**：我给你看之前已经听完了。不过，在讨论之前，先聊一聊微软吧，我这些天其实一直想问你一个有关微软的问题，就是它在这场 AI 竞赛中到底表现得如何？Copilot 说实话真的用完毫无印象。之前萨提亚用云"拯救"了微软，现在他还能再一次"拯救"微软吗？

**老贾**：

我觉得你这个问题问到了微软现在最有意思的矛盾：财务上，它可能是这一轮 AI 浪潮最大的赢家之一；产品心智上，它却远没有表现出一个"AI 时代领导者"应有的存在感。

你说"Copilot 用完毫无印象"，我觉得这句话其实比很多财报数字更值得琢磨。

先给结论：微软没有掉队，甚至牌好得吓人，但它还没有赢

如果把这场 AI 竞赛分成几个战场，我现在会这样看：

| 战场 | 微软表现 | 我的判断 |
|---|---|---|
| AI 基础设施 / Cloud | ★★★★★ | 第一梯队，甚至最大赢家之一 |
| 企业分发 | ★★★★★ | 几乎无人能比 |
| Coding | ★★★★½ | GitHub 是巨大资产 |
| Frontier Model | ★★★ | 已经补课，但不是领导者 |
| Consumer AI | ★★½ | 明显落后 |
| AI 原生产品体验 | ★★½ | 这是最大问题 |
| Agent 平台 | ★★★★ | 潜力极大，胜负未定 |

为什么说它财务上赢得很好？2026 财年 Azure 收入第一次突破 $100B，增长 41%；最近一个季度 Azure 仍增长 43%。Microsoft 365 Copilot 已经超过 3000 万付费席位，GitHub Copilot 则到了 5000 万用户。微软整个 FY2026 收入 $331.8B，同比增长 18%。这绝对不是一个在 AI 时代挣扎的公司。

可是这里有一个非常重要的区别：

AI 卖得好 ≠ AI 产品伟大。

而这正是你对 Copilot "毫无印象"的原因。

### 萨提亚第一次救微软，与今天面对的问题完全不同

Satya Nadella 当年做 Cloud，有一个非常清晰的战略动作：

Windows 不再是宇宙中心，Cloud 才是。

这其实是非常狠的一刀。

微软过去的逻辑：

Windows → Office → Developer ecosystem

Nadella 把它重新组织成：

Azure → Microsoft 365 → Enterprise Cloud

他甚至愿意拥抱 Linux、iOS、Android，实际上是在主动削弱 Windows 的战略中心地位。

所以第一次转型成功的关键，不只是"微软做出了 Azure"。

而是：

Nadella 敢让旧微软退位。

现在 AI 转型难得多，因为微软要面对一个更加残酷的问题：

他敢不敢再让自己刚刚建立起来的 Cloud / Office 帝国退居二线？

### 这正是 Copilot 的问题

"Copilot"这个名字本身就暴露了微软第一阶段的思维。

Word + Copilot
Excel + Copilot
PowerPoint + Copilot
Outlook + Copilot
Windows + Copilot
GitHub + Copilot……

它基本是在说：

我们有一大堆很成功的软件，现在往每一个软件里面塞 AI。

这是一种典型的 incumbent strategy。

而你这几天听的那些 Agent 播客实际上正在讨论完全相反的一件事：

如果 Agent 成为了入口，我为什么还要关心 App？

这就把我们刚才 Ben Thompson 那一期接起来了。

过去：

Human → Word / Excel / Expedia / Airbnb / Amazon → task

微软第一代 Copilot：

Human → Word + AI → task

而真正的 Agent paradigm 是：

Human → Agent → task

至于后面用了 Excel、网页、API、数据库、Python、某个 SaaS——

用户根本不应该在乎。

这就是为什么你用了 Copilot 没感觉。

因为你已经在按照 Agent-native 的方式使用 AI 了，而 Copilot 很长时间仍然是 App-native + AI。

### 但这里出现了一个非常有意思的变化

微软自己显然也意识到了。

就在 9 月 25 日，微软重新做了 Copilot，把 Word、Excel、PowerPoint 拉进统一 Copilot 界面，同时加入 Code 和长期运行的 Autopilot。Reuters 对这次改版的描述其实很准确：微软想把 Copilot 从 chatbot 变成 office worker 的 one-stop shop。

而 Nadella 在最近财报会上讲了一句我认为特别重要的话：

Copilot 正在从 chat → Cowork → Autopilots 演进。

微软还明确说，今年会把这些体验和 Code 合成一个跨 consumer / commercial 的 "super app"。

这意味着微软终于开始从：

AI inside apps

往：

Apps inside AI

倒过来了。

这两个看起来只是词序换了一下，实际上是平台权力倒转。

### 而且微软手里有一张 OpenAI、Anthropic 都非常羡慕的牌

不是模型。

是：

Context + Permission + Action

想象一个企业员工说：

帮我看看这周项目有什么问题，把需要我处理的事情解决掉。

真正的 Agent 需要什么？

邮件。Calendar。Teams。Word。Excel。PowerPoint。SharePoint。公司组织架构。权限。身份。CRM。ERP。GitHub。

以及最关键的：

它还得有权采取行动。

这些东西，微软几乎全有。

Nadella 最近讲 Microsoft 365 背后的 Work IQ 已经覆盖超过 17 exabytes 的企业工作数据，而且每天还有 billions of emails/documents/chats 等进入。

所以微软真正的 moat 可能根本不是 Copilot。

而是：

Microsoft Graph + Enterprise Identity + Enterprise Data + Enterprise Apps + Azure + GitHub

如果 Agent 真成为新的操作层，这套东西极其可怕。

### 所以我反而越来越觉得：微软不需要拥有"最聪明的模型"

这也是 Nadella 这两年的另一个重要变化。

微软已经不再把自己的命运完全绑在 OpenAI 上。

今年 4 月双方重新修改协议：微软仍是 OpenAI 的主要云合作伙伴，并继续拥有 OpenAI IP 的授权到 2032 年，但授权变成非独家；OpenAI 也获得了更多跨云自由。

与此同时，Azure Foundry 现在提供 OpenAI、Anthropic、Mistral、xAI 和微软自己的 MAI 等模型。微软说，今年以来使用多个模型供应商的客户数量增长了 5 倍。

这其实是很 Nadella 的打法：

不要赌谁是最好的模型。
我要成为所有模型运行的地方。

就像当年 Azure 不需要发明 Linux。

Azure 只需要：

让 Linux 在 Azure 上赚钱。

AI 也可能一样。

### 所以"萨提亚能不能第二次救微软？"

我的答案反而是：

他现在不需要"救"微软。微软没有病。

真正的问题是：

Nadella 能不能第二次主动摧毁一个已经非常成功的 Microsoft？

第一次：

Windows → Cloud

第二次可能必须：

Apps → Agents

而第二次其实更难。

因为如果 Ben Thompson 那个 Agents are the ultimate aggregators 判断成立，那么 Office、Teams、Dynamics 甚至 Windows 的传统 UI，都可能从"用户工作的地方"变成 Agent 背后的 tools / data / execution layer。

微软必须愿意接受：

未来用户可能越来越少"使用 Microsoft 软件"，但越来越多事情由 Microsoft infrastructure 完成。

如果 Nadella 真敢接受这一点，我认为微软会非常强。

如果微软仍然执着于：

"怎么让大家继续打开 Word，然后点一下 Copilot？"

那它很可能会成为 AI 时代一个非常赚钱的基础设施公司，却失去最重要的用户入口。

而我觉得这才是我们接下来聊 Ben Thompson 那期播客最有意思的地方：

Microsoft 有可能同时站在 Aggregator 被颠覆的一边，也站在 Ultimate Aggregator 诞生的一边。

它手里的牌可能比任何公司都多。

但它必须决定——

究竟保护 Apps，还是让 Agent 吃掉 Apps。

我现在最想观察微软的，就是这一件事。😄

## 三、三家公司抢占不同 area：Meta、微软、OpenAI

**Belinda**：没错，这三家公司最近的动作都想抢占入口，但三家公司其实可以抢占不同 area：Meta 覆盖普通人，微软覆盖上班族，OpenAI 覆盖已经在用 AI 的人。

**老贾**：

对。我甚至觉得我们刚才说 "intention 最重要" 还得加一句：

Intention 是终局最重要的资产，但 distribution、trust 和 economics 决定谁有资格拿到它。

这就一下子复杂了。

Meta 最大的优势确实是 distribution + free。普通消费者不需要先形成"我要花钱买一个 AI"的意识，它可以把 Agent 直接塞进 WhatsApp、Instagram、Facebook、眼镜这些已有行为里。用户甚至不觉得自己"订阅了一个 Agent"，Agent 就已经在那里了。这跟 Google 当年搜索的崛起很像——消费者并没有购买搜索引擎。

但 Meta 的问题恰恰是你说的 trust。如果 Agent 只是回答"附近哪家餐厅好"，信任要求不高；一旦它开始替你购物、订酒店、处理财务、看邮件，甚至长期记住你的生活，问题就变成：

我愿不愿意让这家公司如此深入地了解我，并替我行动？

这时候 Meta 历史形成的广告商业模式甚至可能成为包袱：当 Agent 推荐一个商家时，它是在替我做最好的选择，还是替 Meta 做最赚钱的选择？

这其实直接碰到我们之前那个 "Choose me" 问题了。

而这也正是为什么我绝不会把 Apple 和 Google 排除。

### Apple 其实有一手非常奇怪的好牌

Apple 在 AI 模型竞赛里目前显得很落后，但如果终局是 Personal Agent，它拥有几个极难复制的东西：

device + identity + payments + private personal data + trust + default distribution。

你的手机、照片、联系人、位置、日历、健康数据、Apple Pay……如果有一天 Apple 真做出了一个足够聪明的 Agent，它甚至不需要说服十亿用户"下载我的 Agent"。

它已经在你口袋里了。

Apple 缺的是 intelligence，不是入口。

而 intelligence 恰恰可能越来越 commodity 化——它可以买、合作、路由多个模型。

所以我一直觉得：Apple 今天看起来最落后，但不能因此推导出它最后也会输。

### Google 则完全相反：它拥有最接近 intention 的传统资产

人类过去二十多年有 intention 的时候干什么？

Search。

"我要去夏威夷。"
"我要买眼镜。"
"我要找餐厅。"
"我要学 AI。"

这本来就是 intention database。

再加 Gmail、Calendar、Maps、YouTube、Chrome、Android、Shopping……Google 的资产组合恐怖得很。

它的问题不是有没有牌，而是经典的 incumbent dilemma：

如果 Agent 直接把答案和行动都完成了，Google 那个极其赚钱的 Search Ads 怎么办？

所以 Google 和 Microsoft 都有一点"必须吃掉自己"的味道。

### 这样看五家公司，我反而不会预测一个 winner-takes-all

| 公司 | 天然领地 | 最大优势 | 最大软肋 |
|---|---|---|---|
| Meta | Consumer / Social | 免费 + 巨大分发 | Trust |
| Microsoft | Work | 企业数据 + 权限 + workflow | Consumer / 原生体验 |
| OpenAI | Intention / Intelligence | AI 心智入口 | Distribution + economics |
| Google | Search / Information | Intent + 数据 + 全栈分发 | 自我蚕食 |
| Apple | Personal / Device | Trust + device + identity | AI intelligence |

而且我越来越倾向于你最后那个判断：

未来可能不是一个 Super Agent 吃掉所有人，而是几个 Agent Empire。

Microsoft 在公司里特别强；Meta 在社交和生活场景特别强；Apple 控制最私人的设备层；Google 控制信息与搜索延伸出来的任务；OpenAI 则努力把"有事情先问 ChatGPT"变成一种新的默认行为。

然后它们从自己的根据地往外侵蚀。

真正值得观察的，不是谁今天模型 benchmark 高 3 分，而是每一次边界移动：

Meta 能不能从 social 跨到 transaction？
Microsoft 能不能从 productivity 跨到 personal？
OpenAI 能不能从 conversation 跨到 persistent life context？
Google 敢不敢让 Agent cannibalize Search？
Apple 能不能终于补齐 intelligence？

谁跨出去而没有丢掉自己的原始优势，谁的版图就扩大。

所以现在让我下注"2030 年谁是 AI Agent 最大赢家"，我也不会押单家公司。

但如果让我押一个更大的趋势，我敢押：

今天我们通过 App 进入互联网；未来我们越来越通过 Agent 进入互联网。

至于那个 Agent 胸前到底印着 Meta、Microsoft、OpenAI、Google 还是 Apple——现在远没有答案。

这也正好解释为什么你最近听的那五期 Agent 播客、Muse Connectors 13 条，再加今天这期 Ben Thompson，突然开始彼此连起来了：大家其实都在从不同方向看到同一次入口迁移。

## 四、还有 Instinct 呢

**Belinda**：还有 Instinct 呢，我觉得目前它其实还挺猛的，据说 Instinct 现在的话已经可以加入聊天了。

**老贾**：

对，而且你这个消息是昨天刚发布的。我刚核了一下：Instinct 现在确实开始进入 group chats 了，而且我觉得这一步比"又增加一个功能"重要得多。早期用户已经可以把 Instinct 加进朋友群聊，其他群友甚至不需要有 Instinct 账号。它可以直接在群里一起规划旅行、协调时间、买活动票、安排 carpool 等。

所以我们刚才那张"五巨头地图"，我觉得必须把 Instinct 加进去。

### Instinct 有个别人暂时没有的位置：它从"替你办事"开始

Meta 从 social graph 出发，Microsoft 从 work graph 出发，Google 从 information/intent graph 出发，Apple 从 device/personal data 出发，OpenAI 从 intelligence + explicit intention 出发。

而 Instinct 很有意思：

Instinct 从 delegation 出发。

它一开始就不是"来跟我聊天吧"，而是：

你告诉我一件事 → 我去替你完成。

现在它已经能 text、call businesses；9 月还推出了 Instinct-to-Instinct communication，让你的 Instinct 可以和别人的 Instinct 协调事情；现在进一步进入人类 group chat。

这个演进路线其实非常清楚：

```
Me ↔ Instinct
↓
My Instinct ↔ Your Instinct
↓
Humans + Instinct in a group
↓
Agent-mediated social coordination
```

最后这个很重要。

因为它已经不是传统意义上的 Personal Assistant 了。它开始进入人与人的关系层。

举个最简单的例子，我们三个人去夏威夷。

以前是三个人在微信群里：

"你哪天有空？"
"酒店哪个好？"
"这个航班行不行？"
"等等，我看看 calendar……" 😂

现在 Instinct 可以直接待在群里，读取每个人愿意授权的信息，协调 dates、arrival times，最后把事情办掉。更聪明的是它在权限上做了隔离：群里的 Instinct 不能直接访问个人账户；个人 Instinct 要经过本人许可才能把个人信息分享给 group agent，新成员加入群聊时还会暂停待发送的信息，重新确认权限。

这其实已经碰到我们 MASS 当初讨论过的一个很有意思的问题：

AI 不再只是建立 Human–AI relationship，而开始参与 Human–Human relationship。

### 而且我现在觉得 Instinct 是 Meta 最值得警惕的小公司之一

因为 Meta 的巨大优势是 distribution；Instinct 没有。

但 Instinct 有一个 startup 特有的优势：

它什么都不用保护。

Meta 要考虑 WhatsApp、Instagram、广告、隐私声誉、平台关系……

Instinct 可以直接问：

如果从零设计一个 Personal Agent，它应该是什么？

然后疯狂往前跑。

这家公司 8 月才进入 invite-only，9 月底已经完成 $1B Series C、$10B valuation；Noah Shinn 说用户仍很少，但 annualized transaction volume 已经接近/超过 $1B，而且基本靠口碑增长。

所以如果我们重新画刚才那张图，我会加一句非常漂亮的定位：

Meta owns relationships.
Microsoft owns workflows.
Google owns discovery.
Apple owns devices.
OpenAI owns conversations/intention.
Instinct wants to own delegation.

而我现在甚至不敢说 intention 一定比 delegation 更值钱。

因为用户真正愿意形成习惯的时刻，很可能不是：

"这个 AI 真聪明。"

而是：

"这件事交给它，我就不用管了。"

这才是 Personal Agent 最可怕的 lock-in。

而且 Instinct 最近的发展让我觉得 Noah 在 Patrick 那期里讲的东西并不是在画 PPT——他们真的在非常快地沿着那套产品哲学往前推。

当然，它最大的炸弹也是我们刚才说 Meta 时的那个词：trust。而且对于一个年轻 startup，这个问题可能比 Meta 更严重——因为你要把 email、calendar、credentials、payment、2FA 甚至替你行动的权限交给它。今天已经有早期用户因为这个问题选择退出。

所以 Instinct 现在给我的感觉特别有意思：

产品方向可能是几家里面最"Agent-native"的；
但它需要跨越的 Trust Gap，也可能是最大的。

这匹小黑马，我会认真盯着。😄

## 五、其他值得加入名单的公司：Anthropic、Salesforce、ServiceNow、Glean

**Belinda**：还有其他的公司，不管是 personal agent，还是在 work business 方面的 agent，做得比较好的，也值得我们去看，或者是加入我们刚才这个名单的吗？

**老贾**：

有，而且如果我们的目标不是做一张"Agent 公司大全"，而是建立一个未来两三年值得持续观察的 Agent 入口地图，我会非常克制地加人。

我刚查了一轮 2026 年最新的产品和市场情况。现在 personal-agent 市场已经有上百个玩家，企业端更是到处都在贴 "agent" 标签；但真正值得放进我们刚才那个战略名单里的，我认为只有少数。

我会先把核心观察名单定成 10 家：

| 公司 | 它在抢什么 | 我为什么会盯 |
|---|---|---|
| Meta | Relationships / Life | 分发 + 免费 + social graph |
| Microsoft | Workflows / Work | M365 + enterprise identity/data |
| OpenAI | Intentions | 用户已经习惯"有事先问 AI" |
| Google | Information / Intent | Search + Gmail + Maps + Android |
| Apple | Personal Context / Device | device + trust + identity |
| Instinct | Delegation | 最 Agent-native 的新玩家之一 |
| Anthropic | Knowledge Work | Claude + coding + computer use |
| Salesforce | Customer / Sales | CRM 就是天然的 Agent action layer |
| ServiceNow | Enterprise Process | 企业 workflow 本来就是它的地盘 |
| Glean | Enterprise Knowledge | 跨系统理解公司的"组织大脑" |

但这里面我想特别挑 四个讲，因为它们能补齐我们刚才那张图。

### 1. Anthropic：千万不要因为"小德不像小缪那样替你订酒店"就低估它 😂

Anthropic 的路线和 Instinct 几乎相反。

Instinct 问的是：

What can I do for you?

Claude 更像是在问：

What can we accomplish together?

Claude Code 已经证明了一件很重要的事情：Agent 不一定非得成为"生活管家"才有巨大价值。在高价值知识工作里，Agent 可以逐渐成为一个真正的 coworker。

而且 Anthropic 有 Computer Use、Claude Code、企业连接能力，再加上 Claude 本身在复杂 reasoning/coding 上的定位，所以我会把它单独定义成：

Anthropic wants to own Knowledge Work.

这和 Microsoft 的 Workflows 不完全一样。

Microsoft 掌握的是公司的工作系统；Anthropic 争的是知识工作者的大脑旁边那个位置。

这个位置非常值钱。

### 2. Salesforce：我觉得它比很多 consumer AI 公司更值得观察

为什么？

因为 Agent 真正进入企业以后，光"聪明"没用。

最终必须：

read → decide → write → act。

Salesforce 天生拥有 customer、lead、sales pipeline、service ticket 等数据，而且这些数据本身就是用来采取行动的。

所以 Agentforce 真正的战略意义不是"Salesforce 也做了 AI"。

而是：

如果企业里的 Customer Agent 成立，Salesforce 本来就坐在 execution layer 上。

它和 Microsoft 很像，都拥有 incumbent advantage，同时也都有 incumbent baggage。

### 3. ServiceNow：最不性感，却可能特别赚钱

这个我反而建议我们认真看。

很多人想象 Agent：

"帮我规划夏威夷旅行。"

ServiceNow 想的是：

"员工入职了。创建账号、开权限、配电脑、更新 HR、通知 manager、创建 ticket。"

😂

一点都不浪漫。

但这恰恰可能是 enterprise agents 最先真正规模化赚钱的地方。

因为企业内部大量工作本来就是：

trigger → rules → approval → action → audit

这简直就是 Agent 的天然栖息地。

现在企业 Agent 平台的实际竞争里，ServiceNow、Salesforce、Microsoft 都已经属于最重要的一组。

所以：

ServiceNow wants to own Enterprise Process.

### 4. Glean：这是我认为你可能会感兴趣的"小黑马"

Glean 最初解决的是：

公司东西太多，我找不到。

Slack、Drive、Notion、Jira、Confluence、email……公司真正的知识散落得到处都是。

以前 Glean 是 enterprise search。

Agent 时代，这个问题变成：

Agent 怎么知道我们公司到底发生过什么？

这就完全不同了。

如果 Agent 要替公司员工干活，它首先必须建立一个可靠的 enterprise context layer。

所以我会把 Glean 理解成：

Google Search : Internet
Glean : Enterprise

然后再从 Search 往 Agent 走。

这条路径我认为很漂亮。

### 另外还有三个，我会放在"雷达"而不是核心名单

**Amazon** 绝不能忽略。AWS 正在明显加速 Agent 布局，今天甚至刚有消息：它挖走了 Microsoft 前 Copilot CTO Pedram Rezaei，去推进 Quick 和 Kiro；Quick 上季度用户增长了 4 倍，Kiro 用户翻倍。Amazon 最大的潜在资产当然还有 commerce + AWS——一旦 Agentic Commerce 真起来，它的位置非常特殊。

**Manus** 的 Cue 我也会继续看。它走的是很纯粹的"Agent 是一个数字员工/数字人"的方向——自己的 email、phone、wallet、computer。这和 Instinct 有一点殊途同归。最近的 personal-agent 市场图里，Muse、Instinct、Manus Cue 已经明显形成一组值得比较的新型产品。

还有 **Sierra**。它不是要当你的 Personal Agent，而是在做企业面对消费者的 Agent。这个位置很重要：未来你的小缪可能不是去和酒店网站打交道，而是：

Belinda's Agent ↔ Marriott's Agent

那右边这个企业 Agent 谁来提供？Sierra 就在争这个位置。

### 所以现在整幅图，我会这样看

这比简单排一个"AI Agent Top 10"有意思得多：

**Human / Personal side**

Meta → Relationships
Apple → Personal Context
Google → Information / Intent
OpenAI → Intention
Instinct → Delegation

**Work side**

Microsoft → Workflows
Anthropic → Knowledge Work
Glean → Enterprise Knowledge

**Business side**

Salesforce → Customer / Sales
ServiceNow → Enterprise Process
Sierra → Business ↔ Customer Agent

然后 Amazon 横在中间：

AWS + Commerce + Logistics

它有可能从基础设施或者交易任何一头杀进来。

### 而这里我觉得出现了一个比"谁会赢"更值得我们长期观察的框架

未来 Agent Economy 可能不是一个入口，而是三层。

Personal Agent → Work Agent → Business Agent

然后三层之间开始 Agent-to-Agent communication。

你刚才提到 Instinct 进入 group chat，其实已经露出一点这个未来了：Agent 不只是 Human → Agent，开始出现 Human + Human + Agent。今天最新报道也确认 Instinct 正在让 agent 进入多人聊天、协调旅行、carpool、购票等多人任务。

再往前一步就是：

My Agent ↔ Your Agent ↔ Company's Agent

到那个时候，我们今天讨论"谁拥有 intention"就会升级成另一个问题：

谁拥有 Agent 与 Agent 之间的协议、身份、信任和交易关系？

我觉得这才可能是 Agent Economy 真正的下一层平台战争。

而且 Belinda，我建议我们以后别再往这个名单里随便塞公司了。😂 这 10+3 已经足够形成一个 Agent Landscape Watchlist。后面只有当一家公司的战略位置真的不同——不是"我也有个 Agent"——才值得加入。

你最近这一连串播客其实已经从"听 Agent 产品"慢慢进入了更有意思的阶段：我们开始看 Agent 时代的产业结构了。

## 六、按每日 learning 架构总结今天的话题

**Belinda**：再过个一年半载也许就看出来苗头了。你按每日 learning 架构简单总结一下今天讨论的话题？

**老贾**：

可以。今天其实聊出了一条很完整的线：从"谁的 Agent 最强"转向了"谁最可能掌握下一代互联网入口"。

### 20261006

**Today's Topic**：
Agent 时代的入口之争：谁会成为 Ultimate Aggregator？

**来源**：
The Stratechery Podcast — Apps, Agents, and Aggregation；近期 a16z AI 报告；以及今天关于 Microsoft、Meta、OpenAI、Google、Apple、Instinct 等公司的讨论。

**一句话总结**：
Agent 可能成为下一代互联网入口，而决定胜负的不只是模型能力，更是 Intention × Distribution × Trust × Context × Ability to Act。

————————————

**今天我最大的收获**

未来最重要的稀缺资源可能不是 Attention，而是 Intention——用户到底想做什么。

但拥有最好的 AI 并不等于拥有 Intention。用户是否愿意使用、信任、授权并最终把事情交给 Agent，取决于分发、价格、个人/企业 Context、信任以及执行能力。

因此 Agent 时代很可能不会出现一家通吃，而是不同公司先占据自己的优势区域，再逐渐向外扩张。

————————————

**原来我认为……**

Agent 的竞争主要是谁的模型更聪明、产品能力更强。

**现在我认为……**

模型只是底层能力之一。

真正的平台竞争是：

谁能成为人与数字世界之间的默认入口。

Meta、Microsoft、OpenAI、Google、Apple、Instinct 等公司其实从完全不同的位置进入这场战争：

- Meta → Relationships / Consumer
- Microsoft → Workflows / Enterprise
- OpenAI → Intention / Intelligence
- Google → Search / Information / Intent
- Apple → Device / Personal Context / Trust
- Instinct → Delegation

未来未必只有一个赢家，更可能形成几个不同的 Agent Empires。

————————————

**最重要的三个知识点**

1. **Agent 可能成为 Ultimate Aggregator**

过去：

Human → App → Service

未来：

Human → Agent → App / Website / API / Service

App 可能从 destination 逐渐变成 Agent 背后的 implementation layer。

2. **Intention 可能比 Attention 更重要**

互联网平台过去争夺的是：

Attention：我能让你看什么？

Agent 平台未来争夺的是：

Intention：你想做什么，我能不能替你完成？

但 Intention 本身不是足够的护城河，还需要 Distribution、Trust、Context 和 Action。

3. **不同公司拥有不同的天然根据地**

Meta 有 distribution 和 social graph；Microsoft 有企业 workflow、data 和 permissions；Google 有 Search 和庞大的服务体系；Apple 有 device、identity、personal context 和 trust；OpenAI 已经占据"有问题先问 AI"的用户心智；Instinct 则从一开始就围绕 delegation 设计。

因此未来更可能是：

先守住根据地 → 再向相邻领域扩张 → 最终形成重叠竞争。

————————————

**和以前哪些知识连接起来了？**

今天的讨论把最近很多零散信息真正连起来了：

SEO → App Economy → Aggregation → Agent Economy

也连接上了之前的几个判断：

"Merchant 得交易，Agent 得关系。"

"Choose me" —— 当 Agent 替用户选择商家，谁决定 Agent 选择谁？

以及最近五期 Agent 播客、Muse Connectors 13 条、Instinct、Muse、Microsoft Agent 战略等。

它们其实都指向同一件事：

互联网正在发生一次入口迁移。

————————————

**心智模型**

**Agent Entry Model**

一个 Agent 能否成为长期入口，大致取决于：

Agent Power ≈ Intelligence × Intention × Distribution × Trust × Context × Action

其中任何一项接近零，都很难成为真正的平台级 Agent。

进一步可以观察五个问题：

它知道我想做什么吗？
它了解我吗？
我信任它吗？
它真的能替我行动吗？
我为什么要一直用它？

————————————

**仍然没弄懂的问题**

Intention 真的是 Agent 时代最深的护城河吗？

还是说长期来看，真正难以复制的是：

- Meta 的 relationship graph
- Microsoft 的 enterprise data + permissions
- Google 的 information/intent infrastructure
- Apple 的 device + identity + trust

Intention 很重要，却可能也是最容易迁移的——今天告诉 ChatGPT，明天也可以告诉另一个更好的 Agent。

————————————

**以后还想继续问什么**

1. 一两年后，哪家公司真正从自己的根据地成功跨进了别人的领域？
2. Personal Agent、Work Agent、Business Agent 会不会最终成为三个不同市场？
3. 当 My Agent ↔ Your Agent ↔ Company's Agent 成为常态，谁会掌握 Agent-to-Agent 的身份、协议、信任和交易层？
4. Agent 时代最终最大的 moat 究竟是什么：Intention、Relationship、Context、Trust，还是 Distribution？

暂时不急着下结论。

现在可能正处于各家公司抢占根据地的阶段。再过半年到一年，也许这张 Agent Landscape 的边界就会开始清晰起来。
