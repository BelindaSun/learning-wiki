# Hardware Map · 硬件世界地图

**核心概念**: 物理上到底有什么，怎么拼成更大的系统？答案不是一条新的路径要背，而是一个会重复的模式——**算力、内存、互连**这三个维度，在芯片里、在服务器里、在整个集群里，一遍又一遍地出现。看懂一次，就能套用到任何尺度。

## 这张图在说什么

[From Silicon to AI](from-silicon-to-ai.md) 已经画过"硅 → 芯片 → 处理器 → 服务器 → 集群 → 数据中心"这条从头到尾的旅程，那张图的一句话说明是"处理器 + 内存 + 互连 = 计算系统"。这张地图要做的，就是把那一句话变成一个可以随身带走的推理工具：

> **算力、内存、互连——这三样东西，在任何一个尺度上都要问一遍。**

一颗芯片里有：核心（算力）、缓存（内存）、片内总线（互连）。
一台服务器里有：CPU/GPU（算力）、RAM/HBM（内存）、NVLink/PCIe（互连）。
一个集群里有：很多台服务器一起算（算力）、数据分布在各处（内存）、网络/InfiniBand（互连）。

同一个问题，问三次，答案分别在不同的尺度上——这就是这张图想让你带走的唯一一件事。

（一个边界提醒：集群尺度上的"内存"，更多是在问"数据和模型状态分布在哪、怎么被访问"，并不是说整个集群有一块像 RAM / HBM 那样统一的物理内存。）

## 三要素，先各给一个锚点

在钻进各个尺度之前，先给这三个维度各一个"本质 + 直觉"的锚点。它们就是 [From Silicon to AI](from-silicon-to-ai.md) 里"算 / 放 / 搬"那三样东西，换个尺度再看一遍：

- **算力（Compute）— 算。** 本质：处理器执行逻辑判断和数学运算（加减乘除、矩阵乘法）的能力。直觉：**厨师**，真正下刀切菜、掌勺炒菜的人。
- **内存（Memory）— 放。** 本质：临时或长期存放计算所需数据的地方，有两个维度——容量（能放多少）和带宽（拿得多快）。直觉：**备料台**，台面多大决定能同时摆多少食材，伸手拿料多快决定炒菜跟不跟得上。
- **互连（Interconnect）— 搬。** 本质：不同计算单元、不同存储之间传数据的物理通道和通信协议。直觉：**传送带 / 公路网**，决定食材能不能及时送到厨师手边、厨师之间怎么配合。

## 处理器不是只有一种

CPU、GPU、其他加速器（比如 TPU），是**同一个问题（怎么提供算力）的不同设计取舍**，不是越新越好的升级关系。这张图只负责告诉你"存在这些不同的设计"；为什么 GPU 恰好特别适合深度学习，是 [CPU vs GPU](cpu-vs-gpu.md) 这篇已经写好的文章要回答的问题。

## 新闻里那些"硬词"，落在哪个格子？

HBM、NVLink、InfiniBand、PCIe 这些看着吓人的缩写，本质上都只是上面矩阵里某个格子的具体产品或协议名——概念还是"算力 / 内存 / 互连"那三样，牌子不用死记，认得出它在哪一格就够了：

| 硬词 | 本质（严谨一点） | 一句话直觉 |
|---|---|---|
| Cache / 寄存器 | 紧挨着 CPU/GPU 核心的高速、小容量存储 | 厨师的上衣口袋：最常用的调料伸手就拿，但装不下多少 |
| HBM（高带宽内存） | 由多层 DRAM die 堆叠而成，再通过先进封装紧贴 GPU / AI 加速器、做高带宽连接 | 贴着灶台的特快传送带：专门喂 GPU 这种"大胃口"的算力 |
| PCIe | 主板上连接 CPU、显卡、网卡等部件的通用高速总线标准 | 市内主干道：什么部件都能接，但速度有上限 |
| NVLink | NVIDIA 专为 GPU↔GPU 做的高带宽私有互连 | GPU 专属高铁：绕开公共主干道，多卡之间传得快得多 |
| InfiniBand | 为高性能计算和数据中心设计的高带宽、极低延迟网络 | 跨城高速公路：成千上万台服务器组网也不容易堵 |

## 穿线场景：一段计算的数据，从集群走到芯片核心

把三个尺度连起来看，一段数据"被算到"之前，大致要从大尺度一路降到小尺度（这是帮你记住层级的直觉路径，不是严格不变的物理流程——真跑推理时，模型权重早就常驻在 HBM 里了）：

```
集群 Cluster
   → InfiniBand（跨城高速）把数据送到目标服务器
服务器 Server
   → PCIe / NVLink（主干道 / 高铁）把数据塞进 GPU 旁边的 HBM
芯片 Chip
   → 片内总线把数据从 HBM 抓进 Cache（上衣口袋）
   → 最后交给 Core（厨师）算出这一步的结果
```

每往下降一个尺度，"算力 / 内存 / 互连"就换成一套更具体的东西，但问的还是同样那三个问题。
