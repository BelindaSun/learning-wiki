## 5 组原子：概念本身

比喻帮助建立直觉，但比喻不是定义。下面是每组原子实际指什么：

**硬件 / 软件**

硬件是执行指令的物理电路和设备（CPU、内存、硬盘、主板等）；软件是存储为指令序列的程序，规定硬件该做什么。硬件不改变自己能做什么，软件决定这一次具体做什么。

**CPU / 内存 / 存储**

CPU（中央处理器）是执行指令、做运算的芯片。内存（RAM）是临时存放当前正在处理的数据的高速存储，断电就清空。存储（硬盘/SSD）是长期保存数据的介质，断电不丢失，但读写速度比内存慢得多。

**代码 / 程序 / 进程 / OS**

代码是人写的、人可读的指令（源代码）。程序是代码经过编译或打包后，可以被执行的文件。进程是程序被加载进内存、实际运行起来的那个实例——同一份程序可以同时开出多个进程，各自占用自己的内存和 CPU 时间。操作系统（OS，比如 Windows / macOS / Linux）是管理硬件资源、调度所有进程、协调软件与硬件之间关系的系统软件。

**客户端 / 服务器 / 网络 / API**

客户端是发起请求的一方（比如浏览器、手机 App）。服务器是接收请求、处理后返回结果的一方（本质上也是一台运行着特定程序的计算机）。网络是客户端和服务器之间传输数据的通道。API（应用程序接口）是服务器规定的"请求该怎么写"的规则——客户端必须按这个格式来问，服务器才知道怎么答。

**核 / 并行 / GPU**

核（core）是处理器里能独立执行指令的最小单元。并行是让多个核同时处理任务，而不是一个核依次排队处理。GPU（图形处理器）的核心数量远多于 CPU，靠大量核心同时做简单重复的计算（比如矩阵运算），这也是深度学习训练依赖 GPU 的原因——但如前面脚注所说，这只是入门近似，GPU 和 CPU 的差异不只是"核更多"，细节见 [CPU vs GPU](cpu-vs-gpu.md)。
