# 贴现率如何决定股票估值：利率 → 估值的传导

**核心概念**: 股票的价格 = 未来现金流的现值；而"现值"要用贴现率把未来的钱折算到今天。贴现率的基石是无风险利率（美债收益率）。所以利率一动，所有股票的估值地基都在动——这就是为什么"美债收益率"能左右整个股市，尤其是成长股。

---

## 核心公式（直觉版）

```
股票价值 ≈ Σ  未来每年的现金流 / (1 + 贴现率)^年数
```

- **贴现率 = 无风险利率（美债收益率）+ 风险溢价**
- 分母里的 `(1+贴现率)^年数` 是"折扣因子"：年数越远、贴现率越高，折扣越狠

---

## 三个关键推论

### 1. 利率 ↑ → 估值 ↓（反向关系）

贴现率变大 → 未来现金流折到今天更不值钱 → 股价该跌。反之利率 ↓ 则托升估值。

> 记忆锚：利率是股票的"分母"。分母变大，分数变小。

### 2. 久期越长的股票，对利率越敏感

这是最重要的一条。

- **成长股 / 未盈利公司**：价值大多来自"很多年以后"的现金流 → 折扣因子的指数很大 → 利率一动，现值剧烈变化 → **对利率最敏感**
- **价值股 / 高分红成熟公司**：现金流"现在就有" → 受利率影响小

> 这解释了为什么加息周期里科技/AI 股跌得比公用事业狠——不是基本面差，是"久期"长。类比：利率是引力，越"轻飘飘悬在未来"的资产，被拽下来越狠。

### 3. 市场交易的是"预期"，不是"现状"

真正驱动收益率的不是 Fed 今天做了什么，而是**市场对 Fed 未来的预期**。所以就业数据、CPI、油价、官员发言，一改变"预期"，收益率当场就动，不用等真的加/降息。

---

## 传导链

```
就业/通胀/油价数据 + Fed 发言
        ↓ 改变市场对 Fed 的预期
     加息/降息概率变化
        ↓
   美债收益率（无风险利率）变动
        ↓ 进入贴现率（分母）
   股票估值重定价 —— 高估值成长股弹性最大
```

---

## 容易搞混的点

- **不是"利率高就一定跌"**：如果盈利增速足够快，能盖过贴现率上升。利率只是分母，分子（现金流）也在变
- **名义利率 vs 实际利率**：真正影响估值的更接近实际利率（名义 - 通胀预期）
- **加息 ≠ 降息周期**：2026 年特殊，Fed 卡在"要不要继续加息"，所以关键词是"加息预期回落"，别默认成降息
